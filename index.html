ChucnyServer

A Pokemon GO server designed to be
Open Source Clean Fast Raw Professional

📁 Overview

ChucnyServer is a custom MITM (man in the middle) 0.29.0 Pokemon GO server written from scratch in Python. The implementation runs a highly modified branch extension of Pokemon-GO-Private-Server structural logic created by @mobraxton5-ux to support custom game client behavior.

🖥️ How to Run

  1. Run the dependency file /scripts/DOWNLOAD.py to install dependencies. Alternatively (recommended) install manually.
  2. Download (DM @chucny on Discord to get the assets if you don't have them).
  3. Run /chucnyserver/__main__.py.
  4. Install the legacy Pokemon GO 0.29.0 APK
  5. Install CA.crt located in/chucnyserver/certs folder path onto your device as a CA Certificate.
  6. Change the phone's Wi-Fi settings to the DNS shown in the server output.
  7. Open Pokemon GO and select the Login with Googleoption.
  8. You're in!

⌨️ How to Use the Terminal Manager Beta

The terminal manager is still in Beta. It might have lots of bugs.

  1. Run /chucnyserver/__main__.py.
  2. Run /chucnyserver/terminal.py.

📝 Features

  • World Manager Manage all PokeStops coordinates, gyms, structures, and events.
  • Community Day Manually launch and test specialized community day events.
  • Gym Battles Deploy and battle Pokémon within target regional gym locations using vintage structural mechanics.
  • OSM POI Importer Batch map up to 10,000 global PokeStops targets at once by targeting public database feeds through direct OpenStreetMap API processing loops.
  • Terminal Manager An alternative, lightweight admin panel manager.
